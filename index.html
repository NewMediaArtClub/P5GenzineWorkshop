Make a coded zine about the internet

This is a zine-making workshop that uses code. It is not a heavy coding course. Paste the working examples, change the marked values, and ask for help when something breaks.

Start with paper. End with paper. Let the browser get strange in between.

2Prepare your files

Collect a small set of photographs, screenshots, error messages, icons and short pieces of writing. Rename files before coding.

UseWorking sizeSuggested source size
Single page800 × 1,236 px1,600 × 2,472 px
Double-page spread1,600 × 1,236 px3,200 × 2,472 px

Photographs

Use JPEG at roughly 75–85% quality. Keep most files below 2 MB.

Transparency

Use PNG for cut-outs, line art and images needing a transparent background.

Filenames

Use short lowercase names without spaces. The examples use image1.jpg.

Folder

Put images inside an assets folder next to your sketch.

3Start the sketch

Use this complete index.html. The required myCanvas container appears before the scripts. Load p5.js first, p5.(gen)Zine second, then your sketch.

    <link rel="stylesheet" href="style.css">

  </head>

    <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.6.0/p5.js"></script>

    <script src="sketch.js"></script>

Now describe the zine. Camera access is off until the selfie step.

sketch.js — starter
const zine = {
  title: "A Small Zine About the Internet",
  author: "YOUR NAME",          // CHANGE THIS
  description: "Eight pages about being online",
  cam: false
};

function setupPage() {
  // Put backgrounds, images, text and shapes here.
}

function drawPage() {
  // Keep this empty until you add movement or live video.
}

Important: the library owns p5’s usual setup() and draw(). Use setupPage() and drawPage() instead. Most of this workshop happens once in setupPage(). Use drawPage() only when something should change continuously.

Build one function: unless a snippet specifically shows drawPage(), add its lines inside your existing setupPage(). Do not create several functions with the same name.

4Pages & coordinates

A single page is 800 × 1,236. A spread is 1,600 × 1,236. The fold of a spread is at x = 800.

Every object starts at the upper-left. Increase x to move right. Increase y to move down.

Most drawing commands begin with a page name: cover.image(), two.text() or back.background().

x: 340
y: 420

5Change backgrounds

Use colour names, hexadecimal colours or RGB values. Add backgrounds first inside setupPage() so they do not cover later material.

One colour per drawing surface
function setupPage() {
  cover.background("#d9ff43");
  one.background("#171717");
  two.background(240, 70, 125);  // red, green, blue
  three.background("lightblue");
  back.background("#d9ff43");
}
Different colours on each half of a spread
function setupPage() {
  one.background("#fffaf0");
  one.leftBackground("#d9ff43");
  one.rightBackground("#ff3b78");
}

6Add images

First declare the image, then load it in preload(). The path must match the folder and filename exactly.

Load an image
let image1;

function preload() {
  image1 = loadImage("assets/image1.jpg");
}

Position and resize

The four numbers are x, y, width and height.

Place the image
// Add this inside setupPage()
// x: 60, y: 180, width: 680, height: 900
cover.image(image1, 60, 180, 680, 900);

Fill a page automatically

Library page helpers
cover.fullPage(image1);
one.leftPage(image1, 0, 0);
one.rightPage(image1, 0, 0);

These helpers preserve the image’s proportions but may extend beyond the visible page. Use manual positioning when the crop matters.

Keep one image straight

No rotation code is needed. This image stays fixed because it is added once inside setupPage().

A fixed, unrotated image
cover.push();
cover.imageMode(CORNER);
cover.image(image1, 60, 180, 680, 900);
cover.pop();

Give one image a fixed angle

rotate() turns the page’s coordinate system around its current origin. The sequence below temporarily moves that origin to the centre of this image, rotates it by a fixed angle, draws it, then restores the page.

One image at a fixed −8° angle
cover.push();                 // 1. save the page settings
cover.translate(400, 620);   // 2. choose the image centre
cover.rotate(radians(-8));   // 3. set a fixed angle
cover.imageMode(CENTER);     // 4. draw from the centre
cover.image(image1, 0, 0, 680, 900);
cover.pop();                  // 5. stop affecting later items

This does not spin. The value -8 never changes, and the block runs once in setupPage(). Use a separate push() and pop() block for every independently rotated image.

7Add text

Treat each piece of text as one item. Save the page settings, set everything that item needs, draw it, then restore the page. The final two numbers position the text.

Position a heading
cover.push();
cover.noStroke();              // no outline around these letters
cover.fill("#171717");
cover.textFont("Arial");
cover.textSize(72);
cover.textAlign(LEFT, TOP);
cover.text("A SMALL ZINE\nABOUT THE INTERNET", 60, 80);
cover.pop();

\n starts a new line. noStroke() removes outlines from items drawn on that page. It would normally remain active for later items, but push() and pop() contain it to this heading.

Rotate one piece of text

One heading at a fixed 6° angle
cover.push();
cover.translate(400, 160);    // centre point of this heading
cover.rotate(radians(6));     // fixed angle, not animation
cover.noStroke();
cover.fill("#171717");
cover.textFont("Arial");
cover.textSize(64);
cover.textAlign(CENTER, CENTER);
cover.text("YOU ARE ONLINE", 0, 0);
cover.pop();

Easy fonts to try

These common browser fonts need no extra files: Arial, Verdana, Trebuchet MS, Georgia, Times New Roman, Courier New and Impact. Generic choices such as sans-serif, serif and monospace are the safest.

p5.(gen)Zine also imports Averia Libre, Bebas Neue, Bungee Shade, Faster One, Inconsolata, Playfair Display, Rubik Puddles and Ultra. Availability depends on the font request loading successfully.

Flow longer writing into columns

textBox() does not ask for a column count. It fills one box from top to bottom, then automatically begins another box to the right. Column count therefore comes from the amount of text, the column width, the column height and the available page width.

Two-column settings on the left-hand page
two.push();
two.noStroke();
two.textSet("Arial", 28, LEFT, 36, "#171717");

two.textBox(
  "My first memory of the internet begins with a sound...",
  60,    // start x
  80,    // start y
  320,   // width of each column
  1000,  // column height
  40,    // gap before the next column
  true   // show blue guides while designing
);
two.pop();

Starting at x = 60, two 320-pixel columns plus a 40-pixel gap use 680 pixels. That fits within the 800-pixel left page. Change true to false before exporting. If the text is long enough, the function may continue into more columns, so check that it has not crossed the fold or page edge.

8Shapes & repeats

Add one shape at a time. Give each shape its own colour, outline and position inside a push()/pop() block. That makes every item independent.

A filled circle with no outline

Circle: fill, no stroke, position and size
one.push();
one.fill("#d9ff43");          // inside colour
one.noStroke();               // no outline
one.circle(300, 420, 180);    // centre x, centre y, diameter
one.pop();

An outlined rectangle with no fill

Rectangle: no fill, stroke, weight and dimensions
one.push();
one.noFill();                 // transparent inside
one.stroke("#ff3b78");       // outline colour
one.strokeWeight(8);          // outline thickness
one.rect(60, 80, 420, 260);  // x, y, width, height
one.pop();

A rotated rectangle

Shapes rotate in the same way as images and text. Translate to the shape’s centre, rotate, then draw the shape around 0, 0.

One rectangle at a fixed −12° angle
one.push();
one.translate(300, 500);      // centre of this rectangle
one.rotate(radians(-12));     // fixed angle
one.rectMode(CENTER);
one.fill("#304cff");
one.stroke("#171717");
one.strokeWeight(6);
one.rect(0, 0, 420, 180);     // width and height
one.pop();

Page drawing settings persist. Calling one.noStroke() affects later items drawn on one until another stroke setting replaces it. It does not affect cover or two. Using push() and pop() for each item is the clearest beginner pattern.

Repeat an image like too many browser windows

Loop across the right-hand page
one.push();
for (let x = 850; x < one.width; x += 180) {
  for (let y = 60; y < one.height; y += 150) {
    one.image(image1, x, y, 140, 100);
  }
}
one.pop();

Apply something to every drawing surface

The all array
for (const page of all) {
  page.push();
  page.noStroke();
  page.fill("#304cff");
  page.circle(40, 40, 20);
  page.pop();
}

9Random & glitch layouts

The library can arrange words or images for you. Keep a random printed composition in setupPage(). Put a deliberately moving glitch in drawPage().

Random text cloud
function setupPage() {
  two.textSet("Arial", 34, LEFT, 40, "#171717");

  two.randomLayout(
    ["refresh", "accept cookies", "someone is typing"],
    7,      // size
    5,      // area used
    12,     // repetitions
    true    // playful size changes
  );
}
Live glitch: image and words
function drawPage() {
  three.background("#171717");  // clear the previous frame
  three.textSet("Arial", 36, LEFT, 42, "#d9ff43");

  three.glitchLayout(
    [image1, "SIGNAL LOST"],
    7,      // size
    5,      // maximum echoes
    18,     // repetitions
    false   // true makes it wilder
  );
}

Why redraw the background? drawPage() runs repeatedly. Without the background line, every glitch frame remains visible and rapidly builds into a dense block. This example clears and redraws the whole three spread, so do not place static content on that spread in setupPage(). Move the glitch to setupPage() if you want one frozen, printable result.

10Add a selfie

Turn the camera on in the zine settings. The browser will ask for permission. Always offer a non-camera alternative.

Enable the webcam
const zine = {
  title: "A Small Zine About the Internet",
  author: "YOUR NAME",
  description: "Eight pages about being online",
  cam: true
};
Fill page seven with the mirrored camera
function drawPage() {
  three.rightBackground("#171717");
  three.push();
  three.translate(1600, 0);  // right edge of the spread
  three.scale(-1, 1);        // mirror the camera
  three.tint(255, 80, 150);  // optional colour tint
  three.image(selfie, 0, 0, 800, 1236);
  three.pop();
}

To cover an entire drawing surface instead, use the library shortcut cover.selfieBackground(255, 80, 150).

Note: camera access normally requires a secure https page. It may fail when opening an HTML file directly from a computer.

11Export, print, fold

Save separate page images for reuse or download the imposed PDF for printing. Make a test print before finalising the composition.

Add simple export buttons
function setupPage() {
  makeButton("Download page images", "downloadJPG");
  makeButton("Download print PDF", "downloadPDF");
}

The bundled PDF is formatted for US Letter. If you are printing on A4, test the printer’s scaling and orientation. Avoid putting essential text against an edge or directly across a fold.

12When it breaks

The page is blank
Check the browser console. Confirm the libraries load before sketch.js. Make sure you used setupPage() and drawPage(), not the standard p5 names.
The image does not appear
Check capital letters, spaces and the file extension. assets/photo.jpg and assets/Photo.JPG are different paths on many web servers.
Drawing appears outside the intended page
Remember that spreads are 1,600 pixels wide. The left page occupies x 0–799 and the right page occupies x 800–1,599.
The random layout flickers
Move the random drawing code from drawPage() into setupPage().
The camera does not start
Set cam: true, allow camera permission and use a secure HTTPS page. Provide a loaded photograph as the fallback.
The PDF looks different from the browser
Interactive elements cannot survive on paper. Check image crops, margins, folds and printer scaling with a low-ink test copy.
